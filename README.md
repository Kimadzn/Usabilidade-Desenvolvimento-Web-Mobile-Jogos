# Usabilidade-Desenvolvimento-Web-Mobile-Jogos

Repositório destinado aos projetos, atividades e trabalhos desenvolvidos na disciplina **Usabilidade – Desenvolvimento Web, Mobile e Jogos**.

## Sobre a Disciplina

A disciplina aborda conceitos e práticas relacionados ao desenvolvimento de aplicações Web, Mobile e Jogos, com foco em **usabilidade, experiência do usuário (UX), acessibilidade e boas práticas de desenvolvimento**.

## Objetivos

* Aplicar conceitos de usabilidade e experiência do usuário.
* Desenvolver interfaces intuitivas e responsivas.
* Utilizar boas práticas de desenvolvimento Web e Mobile.
* Compreender princípios de acessibilidade.
* Desenvolver projetos utilizando diferentes tecnologias.
* Explorar conceitos relacionados ao desenvolvimento de jogos.

## Conteúdos

* Usabilidade e UX/UI
* Design de interfaces
* Desenvolvimento Web
* Desenvolvimento Mobile
* Responsividade
* Acessibilidade
* Interação Humano-Computador
* Desenvolvimento de Jogos
* Prototipação
* Avaliação de interfaces
* Boas práticas de desenvolvimento

## Tecnologias

As tecnologias utilizadas podem variar de acordo com cada atividade e projeto desenvolvido durante a disciplina.
